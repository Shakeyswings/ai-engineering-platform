# Evaluation Rubric

Scoring categories:
- Accuracy: 30%
- Completeness: 20%
- Usability: 15%
- Risk: 15%
- Source quality: 10%
- Format compliance: 10%

Deployment thresholds:
95-100 = Deploy
90-94  = Review then deploy
70-89  = Patch required
Below 70 = Reject

Required result:
Pass / Review / Fail
