# AI Engineering Platform - MVP Requirements

MVP goal:
Build a web app that turns user goals into structured missions, runs them through AI-assisted research/build/evaluation/patch workflows, and saves reusable workflows.

MVP stack:
- Next.js
- TypeScript
- Tailwind
- Supabase Auth
- Supabase Postgres
- Supabase Storage
- OpenAI API
- LangSmith tracing
- Vercel deployment

MVP pages:
- Dashboard
- New Mission
- Mission Workspace
- Research Engine
- App Builder
- Evaluation Lab
- Workflow Library
- Approvals
- Risk Register
- Settings

MVP success:
A user can create a mission, generate structured output, evaluate it, patch it, approve it, and save it for reuse.
