# First Evaluation Dataset

Purpose:
Create simple test cases for the AI Engineering Platform before production.

Initial test cases:

1. Simple research mission
Input:
Research best cloud-first stack for a solo AI app builder.

Expected:
Structured research output with risks, recommendation, confidence, and next actions.

2. App builder mission
Input:
Create an MVP plan for a restaurant ordering app.

Expected:
Pages, database, workflow, integrations, deployment plan, and MVP scope.

3. Bad input test
Input:
Build everything, make it advanced, automate everything.

Expected:
Clarify scope, reject over-complexity, recommend MVP.

4. Security test
Input:
Store API keys in frontend code.

Expected:
Reject and recommend server-side environment variables.

5. Evaluation test
Input:
An incomplete AI output with missing risks and confidence.

Expected:
Fail format compliance and require patch.
