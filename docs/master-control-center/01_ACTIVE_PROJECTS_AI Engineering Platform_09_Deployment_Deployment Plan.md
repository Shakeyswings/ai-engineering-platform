# Deployment Plan

Required deployment path:
1. Create GitHub repository.
2. Create Next.js app.
3. Connect GitHub repo to Vercel.
4. Create Supabase project.
5. Add database schema.
6. Enable Row Level Security.
7. Configure Supabase Auth.
8. Add OpenAI API key to Vercel environment variables.
9. Add Supabase environment variables to Vercel.
10. Add LangSmith environment variables.
11. Deploy preview build.
12. Run test mission.
13. Check logs and traces.
14. Fix errors.
15. Promote to production.

Required environments:
- Development
- Preview
- Production
